    How it works

    From raw data to a live service.

    Learn from history

    An XGBoost model trained on 7,043 past customers, tracked with MLflow and compared against logistic regression.

    Serve through an API

    A FastAPI service validates every request and returns a probability, a yes/no call and a risk level.

    Ship and monitor

    Docker packaging, automated tests on GitHub Actions, and drift checks keep it reliable after launch.
